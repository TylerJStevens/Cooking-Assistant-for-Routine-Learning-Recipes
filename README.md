# Cooking-Assistant-for-Routine-Learning-Recipes
The Cooking Assistant for Routine Learning (or C.A.R.L) was a project my team Honors Engineering 111 and I designed to help unhoused people who were recently housed learn and get into the routine of cooking. Part of this system is a physical light display which shows what tools to use for specific parts of a recipe. This system is controlled via arduino with this program and as such this program was originally devloped through their propreitary IDE.
